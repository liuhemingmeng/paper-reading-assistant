第8周教程：接入真实 Embedding（以火山方舟多模态为例）

前 7 周我们一直用本地哈希基线（LocalHashingEmbedder）跑通整条 RAG 链路——它不需要联网、不需要 Key、结果确定，非常适合开发和测试。但哈希向量是「词面相似」而非「语义相似」，检索质量有天花板。本周我们接入一个真实的语义向量模型，让检索真正理解含义，并为下周的量化对比实验打基础。

目标达成状态： 已用火山方舟 doubao-embedding-vision-251215 完成真实联网调用，返回 2048 维向量，代码改造 + 测试（44 passed）+ 提交均已完成。

1. 为什么需要配置三样东西

项目在启动时调用 get_default_embedder()，它只看一件事：EMBEDDING_BASE_URL / EMBEDDING_API_KEY / EMBEDDING_MODEL 是否三者都填了。

  • 没填全 → 自动回退本地哈希基线（开发默认）。
  • 三样都填 → 切换到 OpenAICompatibleEmbedder，走真实向量模型。

2. 多模态模型的坑（关键）

你用的火山方舟 doubao-embedding-vision-251215 是多模态模型，它的接口和标准 OpenAI 有两处不同，代码必须适配：

维度标准 OpenAI /embeddings火山多模态 /embeddings/multimodal
请求路径.../v1/embeddings.../api/v3/embeddings/multimodal
请求体 input["文本字符串"][{"type":"text","text":"文本字符串"}]
响应 data数组 [{embedding:[...]}]对象 {embedding:[...]}

所以代码里新增了 EMBEDDING_ENDPOINT 变量（默认 /embeddings），当路径含 multimodal 时自动切换输入/输出格式。

3. 配置步骤

① 复制模板

cp .env.example .env

② 填入四个变量（.env 已在 .gitignore 中，不会被提交）

EMBEDDING_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
EMBEDDING_API_KEY=<你的火山方舟 API Key>
EMBEDDING_MODEL=doubao-embedding-vision-251215
EMBEDDING_ENDPOINT=/embeddings/multimodal
注意： EMBEDDING_BASE_URL 填到 /api/v3 即可，/embeddings/multimodal 由 EMBEDDING_ENDPOINT 拼接，二者不能重复写，否则路径会变成 /embeddings/multimodal/embeddings。

③ 重启服务 / 重开终端——环境变量在进程启动时读取，改完要重启才生效。

4. 验证是否配通

一行命令检查当前用的是哪个 embedder：

python -c "from paper_api.embeddings import get_default_embedder; print(type(get_default_embedder()).__name__)"

输出 OpenAICompatibleEmbedder 即真实模型生效；LocalHashingEmbedder 说明变量没填全。

真实联网 smoke（直连，绕过本地代理）：

unset http_proxy https_proxy
python -c "
from paper_api.embeddings import OpenAICompatibleEmbedder
e = OpenAICompatibleEmbedder.from_environment()
out = e.embed('天很蓝')
print('dim=', len(out.vector), 'head=', [round(x,4) for x in out.vector[:5]])
"
本机实测：dim=2048，模型 doubao-embedding-vision-251215，多模态端点生效，返回归一化向量。

5. 一个工程细节：测试隔离

引入真实 .env 后，我们发现原有测试会「隐式依赖无 .env 时回退本地基线」——一旦有了真实配置，测试就去联网导致失败。正确做法是让测试显式注入离线 embedder（client fixture 注入 LocalHashingEmbedder()），并新增一条多模态解析的回归测试。这样测试在 CI 里有真实 .env 也稳定。当前 pytest 结果为 44 passed。
